Filee SVG 版 · 开始使用

Windows x64 免安装包，内含运行库和 Chrome 扩展，无需另装 .NET。请先把整个 ZIP 解压到一个固定文件夹，不要直接在压缩包中运行。

1. 启动 Filee

双击同文件夹内的 Filee.exe。若已经运行其他版本，先从托盘退出旧版。保持普通权限运行，以便接收浏览器拖拽。

2. 首次加载 Chrome 扩展

双击 Install-Chrome-Extension.cmd 可打开说明、扩展文件夹和 Chrome 扩展管理页。此辅助入口不会静默安装扩展或修改浏览器策略。

  1. 在 Chrome 地址栏打开 chrome://extensions。
  2. 开启“开发者模式”，点击“加载已解压的扩展程序”。这不是网页开发者面板。
  3. 选择本包的 browser-extension 文件夹：
    本包所在文件夹\browser-extension
  4. 保留“所有网站”访问权限，然后刷新已经打开的网页。新页面会自动启用，无需逐站点击。

首次加载需要你在 Chrome 中确认。扩展尚未上架 Chrome 商店；普通 Windows Chrome 不支持让 GitHub 下载包静默安装扩展。安装后不要移动或删除扩展文件夹。

3. 直接拖拽图案转换

按住 Ctrl，把鼠标移到网页图片或 SVG 图案上，再拖入 Filee 圆环并选择 PNG 等格式。也可以选中完整 SVG 代码后按原方式拖拽。

扩展会保留路径、常用样式、颜色和同页面引用定义。图片可保留透明背景；空 SVG 或全透明渲染会报错，不再显示为成功的空白图片。

选择圆盘中的下载可直接保存图片，不重新编码。普通图片优先使用网页明确提供的最高分辨率版本。

在设置 → 常规 → 圆盘下载保存位置中，可选择“每次选择位置”“默认保存（系统下载文件夹）”或“指定文件夹”。取消位置选择不会下载；“仅保存转换后文件”不影响下载。更新后请在 Chrome 扩展页重新加载扩展并刷新网页。

范围与版本说明

支持普通 HTTP/HTTPS 顶层网页中的普通图片和内嵌 SVG。Chrome 内部页面、商店页面、跨框架、封闭 Shadow DOM、SVG 引用的外部图片/字体和动画不在支持范围内。普通文件转换无需扩展；部分其他格式依然需要在 Filee 中下载对应转换引擎。

此 Fork 发行版未使用上游作者的代码签名。应用、引擎和扩展已做自动化验证；真实 Chrome 鼠标拖拽到 Filee 尚未完成验证，不宣称所有网站均已实测。

版本、源码提交见 BUILD-INFO.json；文件校验见 FILES-SHA256SUMS.txt。
